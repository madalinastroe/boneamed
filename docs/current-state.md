# Current state

## Status

The repository contains a working Vue/Vite application for the Bonea Med website and a prototype appointment-booking flow.

## Implemented

- Routes exist for home, team, services, contact, booking, and appointment lookup.
- The project includes clinic/service imagery, Romanian site content, and shared CSS.
- The appointment service provides simulated availability, SMS-code requesting, and booking confirmation. The accepted confirmation code is currently hard-coded.

## Appears in progress

- `src/views/home-prototype/` contains three alternate home-page variants alongside the routed home view.

## Obvious issues

- No obvious issue was identified from the brief repository inspection.
